# PhotoFlow by Misantio

**From Capture to Delivery.**

PhotoFlow is an event photography operations system for participant registration, shooting, client galleries, ordering, payments, printing, QC, framing, and delivery.

Current GitHub baseline:
- Premium responsive studio dashboard
- Event operations overview
- Production pipeline
- Recent orders and alerts
- Mobile/tablet responsive layout

Planned modules:
- Events and reusable SCE/PSS/KMS templates
- Participants + QR/nameplates
- Photo Intake and separator-image grouping
- Shooting Mode
- Client Galleries
- Orders and package mockups
- GCash / Maya / Cash payments
- Print Queue
- Production / QC
- Framing
- Delivery Manager
- Reports
- Supabase backend and role-based access

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
