# PhotoFlow

Premium high-volume event photography operations platform by Misantio Studio.

PhotoFlow manages participant registration, QR/nameplate photo assignment, client galleries, ordering, payments, printing, quality control, framing, and delivery from one responsive application.

## Complete workflow

Dashboard → Events → Participants → Nameplates → Photo Intake → Shooting Mode → Client Galleries → Orders → Payments → Print Queue → Quality Control → Framing → Delivery → Reports

## Development

```sh
npm install
npm run dev
```

Production build:

```sh
npm run build
```

Built with TanStack Start, React, TypeScript, Tailwind CSS, and Supabase.
